# Arcana Tabuleiro

Tabuleiro virtual para D&D 2024, em português: mapa, grade, tokens, régua e ping ao vivo entre o mestre
e os jogadores, sem conta. Site estático publicado pelo GitHub Pages (pasta `docs/`).

Site: https://thiagolevin-2.github.io/Arcana-Tabuleiro/

## Créditos e licenças
- **PeerJS 1.5.4** (`docs/vendor/peerjs-1.5.4.min.js`): licença MIT, texto em `docs/vendor/peerjs-LICENSE.txt`.
  O servidor público gratuito do PeerJS só ajuda os aparelhos a se encontrarem; os dados vão direto entre eles (WebRTC).
